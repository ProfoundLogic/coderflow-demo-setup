# Widget: `field set panel`

Use `"field type": "field set panel"` on an item to render this widget.

Properties below are **specific to `field set panel`** (plus any other widgets they also apply to). For properties that apply to every widget (id, position, font, borders, padding, events, validation, etc.) see [_universal.md](_universal.md).

Specific property count: **6** · Combined with universal: **96**
## Menu Options

### `border color`

**Type:** `color` · **Default:** `css`

The color of the border used for menu options.

## Borders

### `border width`

**Default:** `css` · **Format:** `px`

**Choices:** `0px`, `1px`, `2px`, `3px`, `4px`, `5px`, `Other...`

The thickness of the grid's outer borders and inner separators.

## Template Settings

### `legend`

**Default:** `Field Set`

Text to display in the field set's legend.

### `legend align`

**Default:** `left`

**Choices:** `left`, `center`, `right`

The alignment of the legend text.

### `legend style`

**Type:** `long`

Styling for the legend text.

### `border style`

**Default:** `css`

**Choices:** `none`, `dotted`, `dashed`, `solid`, `double`, `groove`, `ridge`, `inset`, `outset`

The style of the element's border.
