# Widget: `slider`

Use `"field type": "slider"` on an item to render this widget.

Properties below are **specific to `slider`** (plus any other widgets they also apply to). For properties that apply to every widget (id, position, font, borders, padding, events, validation, etc.) see [_universal.md](_universal.md).

Specific property count: **5** · Combined with universal: **95**
## Field Settings

### `orientation`

**Default:** `theme`

**Choices:** `horizontal`, `vertical`

Specifies the orientation of a slider or a menu element.

### `min value`

**Default:** `blank` · **Format:** `number`

Defines the minimum value for a spinner or slider element.

### `max value`

**Default:** `blank` · **Format:** `number`

Defines the maximum value for a spinner or slider element.

### `increment value`

**Default:** `1` · **Format:** `number`

Specifies how much the value in a spinner or slider element increases or decreases.

## Validation

### `set as modified`

**Type:** `boolean` · **Default:** `blank` · **Bind data types:** `indicator`, `expression`

**Choices:** `true`, `false`

Marks an input field as modified when it is first displayed.
