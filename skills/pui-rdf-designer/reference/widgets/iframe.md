# Widget: `iframe`

Use `"field type": "iframe"` on an item to render this widget.

Properties below are **specific to `iframe`** (plus any other widgets they also apply to). For properties that apply to every widget (id, position, font, borders, padding, events, validation, etc.) see [_universal.md](_universal.md).

Specific property count: **2** · Combined with universal: **92**
## Field Settings

### `iframe url`

**Type:** `long` · **Default:** `blank`

Specifies the content url for an IFrame (inline frame) element.

### `frame border`

**Default:** `true`

**Choices:** `true`, `false`

Determines whether the IFrame (inline frame) element will have a border.
